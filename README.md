# Wedding Mandap 3D

An interactive static wedding venue with sunset/evening lighting, camera presets, a floor plan, and a walk-in tour. Three.js and OrbitControls are vendored; Google Fonts is optional.

## Run locally

Run `python -m http.server 8080` from this directory and open the local server in a browser with WebGL support.

## Publish with GitHub Pages

In repository Settings → Pages, choose **Deploy from a branch**, select **main** and **/ (root)**, then Save. No build step is required.
